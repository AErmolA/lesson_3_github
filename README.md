# Ovik Checker

Программа для автоматической проверки
проектной документации по ОВиК.

## Состав проекта

- src — исходный код
- docs — документация
- tests — тесты





# Здесь:
- ovik-checker — основная папка проекта.
- src — папка с исходным кодом программы.
- docs — папка с документацией.
- tests — папка с тестами.
- README.md — описание проекта.
- requirements.txt — список зависимостей Python.

# Файловая структура:
# src	Обычная папка, содержащая файлы программы
# main.py	Файл с кодом Python
# script.js	Файл с кодом JavaScript
# README.md	Текстовый файл с разметкой Markdown
# settings.json	Файл настроек в формате JSON
# .gitignore	Список файлов и папок, которые Git не должен отслеживать
# .git	Скрытая служебная папка Git с данными репозитория
